# Security policy

Only the latest minor version of the extension and of the MCP server (`@nokxs/iobroker-mcp`) is
supported with security fixes.

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/nokxs/iobroker-javascript-vs-code-extension/security/advisories/new)
instead of a public issue. Include the affected version, the configuration and a reproduction if
possible. You will get an answer as soon as the report has been reviewed.

The MCP server holds an ioBroker session with administrative rights. Never paste real ioBroker
credentials, tokens or log lines that contain personal data into a public issue.
